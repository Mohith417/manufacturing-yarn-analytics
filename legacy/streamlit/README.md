# Legacy Streamlit prototype

Superseded by the React dashboard in `dashboard/`. This copy is kept for
reference and is not needed to build or run the current site.

```powershell
.venv\Scripts\Activate.ps1
streamlit run legacy\streamlit\app.py
```

It reads the CSV exports in `dashboard/data/` and never connects to the cluster.
The current dashboard is documented in `dashboard/README.md`.
